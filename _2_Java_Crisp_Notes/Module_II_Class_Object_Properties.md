# Module II: Class & Object Properties

## Basic Concepts of Java Programming

### Advantages of Java
1. **Platform Independence**: Write once, run anywhere (WORA)
2. **Object-Oriented**: Pure object-oriented language
3. **Robust**: Strong memory management and exception handling
4. **Secure**: Runs in virtual machine sandbox
5. **Multithreaded**: Supports concurrent programming
6. **Dynamic**: Capable of adapting to evolving environments
7. **Architecture Neutral**: No implementation-dependent features
8. **Portable**: Same behavior on all platforms
9. **High Performance**: JIT (Just-In-Time) compilation

### Byte-code & JVM
- **Byte-code**: Intermediate code generated by Java compiler (.class files)
- **JVM (Java Virtual Machine)**: Executes the byte-code
- **Process**:
  1. Java program (.java file) → Java Compiler → Byte-code (.class file)
  2. JVM loads, verifies, and executes the byte-code
- **Advantage**: Platform independence, as JVM is platform-specific but byte-code is not

```
┌─────────────┐    ┌──────────┐    ┌─────────┐    ┌───────────┐
│  Java Code  │ → │ Compiler  │ → │ Bytecode │ → │    JVM    │ → Execution
└─────────────┘    └──────────┘    └─────────┘    └───────────┘
```

## Java Language Fundamentals

### Data Types
1. **Primitive Data Types**:
   - **boolean**: `true` or `false` (1 bit)
   - **byte**: -128 to 127 (8 bits)
   - **short**: -32,768 to 32,767 (16 bits)
   - **int**: -2^31 to 2^31-1 (32 bits)
   - **long**: -2^63 to 2^63-1 (64 bits)
   - **float**: Single-precision floating-point (32 bits)
   - **double**: Double-precision floating-point (64 bits)
   - **char**: Single Unicode character (16 bits)

2. **Reference Data Types**:
   - **Class objects**
   - **Arrays**
   - **Interface variables**

### Access Specifiers
- **public**: Accessible from any class
- **protected**: Accessible within the same package and subclasses
- **default** (no modifier): Accessible only within the same package
- **private**: Accessible only within the same class

| Access Modifier | Class | Package | Subclass | World |
|-----------------|-------|---------|----------|-------|
| public          | Yes   | Yes     | Yes      | Yes   |
| protected       | Yes   | Yes     | Yes      | No    |
| default         | Yes   | Yes     | No       | No    |
| private         | Yes   | No      | No       | No    |

### Operators
1. **Arithmetic**: `+`, `-`, `*`, `/`, `%`
2. **Relational**: `==`, `!=`, `>`, `<`, `>=`, `<=`
3. **Logical**: `&&`, `||`, `!`
4. **Assignment**: `=`, `+=`, `-=`, `*=`, `/=`, `%=`
5. **Increment/Decrement**: `++`, `--`
6. **Bitwise**: `&`, `|`, `^`, `~`, `<<`, `>>`, `>>>`
7. **Ternary**: `? :`
8. **instanceof**: Tests if an object is an instance of a class

### Control Statements & Loops
1. **Decision Making**:
   - `if`, `if-else`, `if-else-if`, `switch`
   
2. **Loops**:
   - `for`: `for(initialization; condition; iteration) { body }`
   - `while`: `while(condition) { body }`
   - `do-while`: `do { body } while(condition);`
   - Enhanced `for` (for-each): `for(Type item : collection) { body }`
   
3. **Branching**:
   - `break`: Exits a loop or switch statement
   - `continue`: Skips the current iteration
   - `return`: Exits from a method

### Arrays
- Collection of similar type elements stored at contiguous memory locations
- Fixed size, once created
- Zero-indexed (first element at index 0)

```java
// Declaration and initialization
int[] numbers = new int[5];  // Creates array of 5 integers
int[] scores = {95, 85, 75, 90, 80};  // Initialization with values

// Accessing elements
int firstScore = scores[0];  // 95
scores[2] = 78;  // Changing value at index 2

// Multidimensional arrays
int[][] matrix = new int[3][3];  // 3x3 matrix
int[][] grid = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};
```

## Class & Object Concepts

### Creation of Class
- A class is a blueprint for creating objects
- Contains fields (attributes) and methods (behaviors)

```java
public class Car {
    // Fields
    String model;
    String color;
    int year;
    
    // Methods
    void startEngine() {
        System.out.println("Engine started");
    }
    
    void drive() {
        System.out.println("Car is moving");
    }
}
```

### Object Creation
- Objects are instances of a class
- Created using the `new` keyword

```java
Car myCar = new Car();  // Creating a Car object
myCar.model = "Toyota";
myCar.color = "Blue";
myCar.year = 2022;
myCar.startEngine();
myCar.drive();
```

### Constructor
- Special method used to initialize objects
- Same name as the class
- No return type (not even void)
- Called automatically when an object is created

```java
public class Student {
    String name;
    int age;
    
    // Default constructor
    Student() {
        name = "Unknown";
        age = 0;
    }
    
    // Parameterized constructor
    Student(String n, int a) {
        name = n;
        age = a;
    }
}

// Using constructors
Student s1 = new Student();  // Default constructor
Student s2 = new Student("John", 20);  // Parameterized constructor
```

### Finalize and Garbage Collection
- **Garbage Collection**: Automatic memory management in Java
- Objects with no references are eligible for garbage collection
- `System.gc()` suggests (but doesn't guarantee) the JVM to run garbage collection
- **Finalize**: Method called by garbage collector before object destruction

```java
protected void finalize() throws Throwable {
    // Cleanup code
    super.finalize();
}
```

### Method Overloading
- Multiple methods with the same name but different parameters
- Resolved at compile-time (static polymorphism)

```java
class Calculator {
    // Method overloading
    int add(int a, int b) {
        return a + b;
    }
    
    double add(double a, double b) {
        return a + b;
    }
    
    int add(int a, int b, int c) {
        return a + b + c;
    }
}
```

### This Keyword
- References the current object
- Used to:
  - Refer to instance variables when hidden by local variables
  - Call another constructor
  - Return the current object

```java
public class Person {
    String name;
    int age;
    
    // Constructor
    Person(String name, int age) {
        this.name = name;  // 'this' refers to instance variable
        this.age = age;
    }
    
    // Using 'this' to call another constructor
    Person(String name) {
        this(name, 0);  // Calls the parameterized constructor
    }
    
    // Returning 'this'
    Person setAge(int age) {
        this.age = age;
        return this;  // Returns the current object
    }
}
```

### Objects as Parameters & Methods Returning Objects
```java
class Rectangle {
    int length, width;
    
    Rectangle(int l, int w) {
        length = l;
        width = w;
    }
    
    // Method that takes an object as parameter
    boolean isLargerThan(Rectangle other) {
        return (this.length * this.width) > (other.length * other.width);
    }
    
    // Method that returns an object
    Rectangle createNewRectangle(int factor) {
        return new Rectangle(this.length * factor, this.width * factor);
    }
}
```

### Call by Value & Call by Reference
- **Call by Value**: Copy of the value is passed (for primitives)
- **Call by Reference**: Reference to the object is passed (for objects)

```java
void changeValues(int x, Person p) {
    x = 10;  // Won't affect original variable (call by value)
    p.name = "Jane";  // Will affect original object (call by reference)
}
```

### Static Variables & Methods
- **Static Variables**: Shared among all instances of a class
- **Static Methods**: Can be called without creating an object

```java
public class Counter {
    static int count = 0;  // Static variable
    
    Counter() {
        count++;  // Increments the shared counter
    }
    
    static void displayCount() {  // Static method
        System.out.println("Count: " + count);
    }
}

// Usage
Counter.displayCount();  // Calling static method without object
```

### Nested & Inner Classes
- **Nested Class**: A class within another class
- **Types**:
  1. **Static Nested Class**: Static class inside another class
  2. **Inner Class**: Non-static class inside another class
  3. **Local Inner Class**: Class inside a method
  4. **Anonymous Inner Class**: Class without a name

```java
class Outer {
    int x = 10;
    
    // Static nested class
    static class StaticNested {
        void display() {
            // Cannot access non-static members directly
        }
    }
    
    // Inner class
    class Inner {
        void display() {
            System.out.println("x = " + x);  // Can access outer class members
        }
    }
    
    void methodWithLocalClass() {
        // Local inner class
        class Local {
            void display() {
                System.out.println("Local class");
            }
        }
        
        Local local = new Local();
        local.display();
    }
}
```

## String Handling

### String Class
- Immutable sequence of characters
- Common methods:
  - `charAt(int index)`: Returns character at specified index
  - `compareTo(String another)`: Compares two strings lexicographically
  - `equals(Object another)`: Checks if strings are equal
  - `equalsIgnoreCase(String another)`: Checks if strings are equal, ignoring case
  - `indexOf(String str)`: Returns index of first occurrence of str
  - `length()`: Returns string length
  - `substring(int beginIndex)`: Returns substring from beginIndex
  - `substring(int beginIndex, int endIndex)`: Returns substring from beginIndex to endIndex-1
  - `toCharArray()`: Converts string to char array
  - `toLowerCase()`: Converts to lowercase
  - `toString()`: Returns string representation
  - `toUpperCase()`: Converts to uppercase
  - `trim()`: Removes whitespace from both ends
  - `valueOf(Object obj)`: Converts to string

```java
String s1 = "Hello";
String s2 = "hello";

char c = s1.charAt(0);  // 'H'
int comparison = s1.compareTo(s2);  // -32 (H is before h in ASCII)
boolean equal = s1.equals(s2);  // false
boolean equalIgnoreCase = s1.equalsIgnoreCase(s2);  // true
int index = s1.indexOf('e');  // 1
int length = s1.length();  // 5
String sub1 = s1.substring(2);  // "llo"
String sub2 = s1.substring(1, 4);  // "ell"
char[] chars = s1.toCharArray();  // {'H', 'e', 'l', 'l', 'o'}
String lower = s1.toLowerCase();  // "hello"
String upper = s1.toUpperCase();  // "HELLO"
String trimmed = "  Hello  ".trim();  // "Hello"
String str = String.valueOf(42);  // "42"
```

### StringBuffer Class
- Mutable sequence of characters
- Thread-safe (synchronized)
- Common methods:
  - `append(String s)`: Appends string to buffer
  - `capacity()`: Returns current capacity
  - `charAt(int index)`: Returns character at specified index
  - `delete(int start, int end)`: Removes substring
  - `deleteCharAt(int index)`: Removes character at index
  - `ensureCapacity(int minimumCapacity)`: Ensures capacity
  - `getChars(int srcBegin, int srcEnd, char[] dst, int dstBegin)`: Copies characters to array
  - `indexOf(String str)`: Returns index of first occurrence
  - `insert(int offset, String str)`: Inserts string at position
  - `length()`: Returns length
  - `setCharAt(int index, char ch)`: Sets character at index
  - `setLength(int newLength)`: Sets length
  - `substring(int start)`: Returns substring
  - `substring(int start, int end)`: Returns substring
  - `toString()`: Converts to string

```java
StringBuffer sb = new StringBuffer("Hello");

sb.append(" World");  // "Hello World"
int capacity = sb.capacity();  // Default is 16 + string length
char c = sb.charAt(0);  // 'H'
sb.delete(5, 11);  // "Hello"
sb.deleteCharAt(0);  // "ello"
sb.ensureCapacity(50);  // Ensures capacity is at least 50
char[] dst = new char[5];
sb.getChars(0, 4, dst, 0);  // Copies "ello" to dst
int index = sb.indexOf("l");  // 0 (after deleteCharAt)
sb.insert(0, "H");  // "Hello"
int length = sb.length();  // 5
sb.setCharAt(1, 'E');  // "HEllo"
sb.setLength(3);  // "HEl"
String sub = sb.substring(1);  // "El"
String str = sb.toString();  // "HEl"
```

### Mutable vs Immutable Strings
- **Immutable String**: Cannot be changed after creation (String class)
- **Mutable String**: Can be modified after creation (StringBuffer, StringBuilder)
- Use String for constants, StringBuffer for threads, StringBuilder for better performance

## I/O Operations

### BufferedReader
- Reads text from a character-input stream
- Buffers characters for efficient reading

```java
import java.io.*;

public class BufferedReaderDemo {
    public static void main(String[] args) throws IOException {
        BufferedReader reader = new BufferedReader(new InputStreamReader(System.in));
        
        System.out.print("Enter your name: ");
        String name = reader.readLine();
        
        System.out.print("Enter your age: ");
        int age = Integer.parseInt(reader.readLine());
        
        System.out.println("Name: " + name + ", Age: " + age);
        
        reader.close();
    }
}
```

### Scanner
- Simple text scanner for parsing primitives and strings
- More convenient than BufferedReader

```java
import java.util.Scanner;

public class ScannerDemo {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.print("Enter your name: ");
        String name = scanner.nextLine();
        
        System.out.print("Enter your age: ");
        int age = scanner.nextInt();
        
        System.out.println("Name: " + name + ", Age: " + age);
        
        scanner.close();
    }
}
